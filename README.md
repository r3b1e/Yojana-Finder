# 🌟 Yojana Finder

**Yojana Finder** is a comprehensive web platform designed to **bridge the gap between Indian citizens and government welfare schemes**.  
With an intuitive interface and powerful search capabilities, users can easily **discover, filter, and apply** for schemes tailored to their needs.

---

## ✨ Key Features

### 🔍 Advanced Search & Filtering
- Real-time search across scheme names, descriptions, and benefits  
- Multi-level filtering (**Central/State** government schemes)  
- Category-based filtering (Agriculture, Healthcare, Education, etc.)  
- Tag-based search for quick discovery  
- Date range filtering for recently updated schemes  

### 🌐 Bilingual Support
- Complete content in **English** and **Hindi**  
- Easy language toggle on all pages  
- Localized scheme descriptions and benefits  

### 💾 Save & Organize
- Save favorite schemes using **localStorage**  
- Personalized **Saved Schemes** page  
- Quick access to bookmarked schemes  

### 📊 Comprehensive Scheme Details
- Detailed information on benefits and financial assistance  
- Step-by-step **application process**  
- Required documents checklist  
- Eligibility criteria breakdown  
- Direct links for online applications

## 🛠️ Tech Stack

### 🖥️ Frontend
- **React 18** – Component-based UI library  
- **Vite** – Next-generation frontend tooling  
- **Tailwind CSS** – Utility-first CSS framework  
- **Lucide React** – Beautiful icon library  
- **React Router DOM** – Client-side routing  
- **Redux Toolkit** – State management  
- **Axios** – HTTP client for API calls  

### ⚙️ Backend
- **Node.js** – JavaScript runtime  
- **Express.js** – Web application framework  
- **MongoDB** – NoSQL database  
- **Axios** – HTTP client  

### 🌏 Translation & Localization
- **LibreTranslate** – Open-source translation engine  
- **Docker** – Containerization for LibreTranslate locally
- **Docker Compose** – Multi-container orchestration  

### 🧠 Data Scraping & Processing
- **Python 3.x** – Data scraping runtime  
- **Beautiful Soup** – HTML parsing library  
- **Scrapy** – Web scraping framework  
- **Requests** – HTTP library for Python
